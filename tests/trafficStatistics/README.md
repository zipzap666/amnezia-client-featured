# Статистика трафика Windows

Страница открывается кнопкой с графиком функции в нижней панели Windows.
В настройках дублирующего пункта нет. Графики построены на
QML Canvas без новых библиотек. Английские строки находятся в QML, русские —
в `client/translations/amneziavpn_ru_RU.ts`.

## Источники и смысл измерений

| Метрика | Источник | Ограничения |
| --- | --- | --- |
| VPN, OpenVPN | Накопительные `>BYTECOUNT` из management interface | Первый отсчёт устанавливает базу; уровень учёта определяется OpenVPN |
| VPN, WireGuard / AmneziaWG / AmneziaWG2 | Существующий read-only status службы, счётчики выбранного peer из UAPI | JSON службы передаёт числа через double; это счётчики peer, а не объём полезных данных приложения |
| Всего на физических адаптерах | `GetIfTable2`, сумма `InOctets` / `OutOctets` активных hardware interfaces | Включает шифрованный VPN, LAN, multicast/broadcast и прочий трафик на этих интерфейсах |
| В обход VPN | Недоступно | Вычитание несопоставимых счётчиков разных уровней не даёт достоверного результата, включая split tunneling |
| VPN, Xray / SSXray / IKEv2 | Недоступно | В текущем клиенте нет подключённого достоверного источника счётчиков этих протоколов |

IN означает получение этим компьютером, OUT — отправку. Скорости указаны в
байтах/с с двоичными приставками КиБ/МиБ, объёмы — в байтах/КиБ/МиБ/ГиБ.
Графики VPN и физических интерфейсов нельзя складывать.

WinAPI выполняется в QtConcurrent с одним запросом в работе; выделенную таблицу
освобождает RAII через `FreeMibTable`. Интерфейсы определяются по LUID и флагам
Windows, а не по отображаемому имени. Виртуальные, loopback, tunnel и filter
interfaces исключены. Учитываются все активные физические подключения. Если их
нет либо запрос завершился ошибкой, метрика недоступна. Информация об API:
[Microsoft GetIfTable2](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/nf-netioapi-getiftable2).

## Время, сбросы и пропуски

- Скорость = разность накопительных байтов / фактический интервал
  `QElapsedTimer`. Опрос — примерно раз в секунду, без сетевых запросов для
  генерации нагрузки.
- Первый отсчёт, смена набора LUID, уменьшение любого из счётчиков отдельного
  адаптера и интервал свыше 5 секунд устанавливают новую базу. Такой интервал
  не включается в объём и образует разрыв на графике.
- Скорость становится недоступной через 3,5 секунды без свежего отсчёта.
  Нулевой трафик показывается только для двух пригодных одинаковых счётчиков.
  До первого пригодного интервала объёмы также показываются прочерком.
- Общие объёмы накапливаются в течение работы приложения, до сброса статистики.
  VPN-объёмы и история очищаются при каждом изменении состояния подключения,
  а также при ручном сбросе. Учитываются только наблюдавшиеся интервалы.
- Сигналы прежнего протокола отсоединяются; поколение подключения дополнительно
  отсекает уже поставленные в очередь сигналы. В WireGuard допускается один
  ожидающий status-запрос; ответы старого поколения и ответы старше 3 секунд
  исключаются. При отсутствии ответа данные становятся недоступны, запросы
  не накапливаются. Подтверждение отключения снимает ожидание старого запроса.
- Ответ WinAPI после сброса статистики или с задержкой свыше 3 секунд
  отбрасывается. Фоновая задача не держит указатель на контроллер.
- Для каждой серии хранится не более 301 точки и не более 5 минут истории.
  Снимки не записываются в настройки. Ручной сброс не управляет VPN.

Служба, драйверы, маршруты, firewall, kill switch, настройки и механизм слепков
не изменены. Изменения сбора данных и защита старого Windows-сигнала дельт
от переполнения ограничены Windows; поведение мобильных протоколов сохранено.

## Автоматическая проверка

В командной строке Visual Studio после `vcvarsall.bat amd64`:

```bat
set PATH=C:\Qt\6.10.1\msvc2022_64\bin;%PATH%
cmake -S tests\trafficStatistics -B deploy\build\trafficStatisticsChecks -DCMAKE_PREFIX_PATH=C:\Qt\6.10.1\msvc2022_64
cmake --build deploy\build\trafficStatisticsChecks --config Release -- /m:2 /nr:false
lrelease client\translations\amneziavpn_ru_RU.ts -qm deploy\build\trafficStatisticsChecks\ru.qm
ctest --test-dir deploy\build\trafficStatisticsChecks -C Release --output-on-failure
```

`trafficStatisticsTests` проверяет интервалы 0,5/1/2 секунды, первый отсчёт,
реальный ноль, уменьшение счётчиков, смену источника, сон/пропуск, устаревание,
нулевой интервал, восстановление, ограничение истории, сброс, переподключение
и сигналы старого протокола. Также выполняется настоящий read-only запрос
WinAPI без подключения к службе VPN.

`trafficStatisticsUiSmoke` открывает только изолированную страницу с подставными
источниками, проверяет горизонтальные границы элементов и отсутствие QML warnings,
рендерит русские подписи штатным шрифтом при ширине 320 и 360 пикселей. Снимки
`statistics-ru-*.png` сохраняются в каталоге сборки тестов. Подставные значения
существуют только в тесте.

`trafficNavigationSmoke` рендерит настоящие `PageStart` и `PageStatistics` с
подставными остальными страницами и контроллерами. Проверяет порядок «Главная → Поделиться → Статистика
→ Настройки → Добавить», переход кнопкой статистики, подсветку,
возврат на главную по Escape, работу при скрытой кнопке Share и размеры кнопок
на ширине 320/360 пикселей. Снимки: `navigation-320.png` и
`navigation-360-no-share.png`. На Windows статистика имеет индекс 2, настройки —
3, добавление — 4; на других платформах порядок и индексы прежние.
Кнопка назад на корневой вкладке
статистики отсутствует вместе с занимаемым ею местом; Escape возвращает на
главную. Для программного открытия страницы поверх другой страницы стрелка
возврата сохраняется; этот запасной сценарий также проверяется тестом.

Большие пояснения по умолчанию скрыты под кнопкой «Как считаем трафик».
QML-тест также проверяет их раскрытие и повторное скрытие. Общий график явно
подписан как включающий VPN и локальную сеть; он не является графиком обхода.

Для проверки payload установщика из окружения Visual Studio:

```bat
python tests\trafficStatistics\verifyPackage.py "deploy\build\_CPack_Packages\win64\IFW\AmneziaVPN_5.0.3.0_windows_x64\packages\AmneziaVPN\data" "deploy\build\traffic-statistics-package-manifest.json"
```

Скрипт не исполняет файлы пакета: `dumpbin /dependents` проверяет обычные и
отложенные импорты каждого EXE/DLL относительно payload и System32; API-set
contracts предоставляет Windows. JSON содержит список зависимостей, размеры и
SHA-256 всех файлов payload. В частности проверяются Visual C++ runtime,
`vc_redist.x64.exe`, `dxcompiler.dll`, `dxil.dll`, Qt, плагины, переводы и
штатные VPN-компоненты. Это статическая проверка состава, а не тест установки.

## Ручная проверка пользователем

Реальное сетевое подключение, установка и переключение действующего VPN
автоматически не выполнялись. Не проверены на живом подключении разные протоколы,
split tunneling, смена сетевого адаптера, сон/пробуждение и работа рядом с zapret.

1. В удобное время запустите тестовую сборку с собственным контролем
   автоподключения. Откройте статистику в нижней панели. Без VPN его счётчики должны
   быть недоступны; физические — поступать при активном сетевом интерфейсе.
2. Подключите OpenVPN или WireGuard/AmneziaWG. Дождитесь двух отсчётов.
   Во время обычного скачивания должен расти IN, при отправке — OUT.
   Переключите 60 секунд / 5 минут и проверьте единицы и легенду.
3. При включённом split tunneling создайте обычный трафик выбранных приложений.
   Физический график включает оба пути; «В обход VPN» остаётся недоступным.
   Не ожидайте равенства сумм или разностей этих графиков.
4. Сбросьте статистику: объёмы и история очищаются, VPN остаётся подключённым.
   Проверьте отключение, повторное подключение и смену протокола: старые точки
   VPN не должны переноситься в новое подключение. Для Xray/IKEv2 — прочерки.
5. При желании проверьте смену Wi-Fi/Ethernet и сон: после перерыва нужна новая
   база, без огромных пиков. В узком окне проверьте вертикальную прокрутку.
